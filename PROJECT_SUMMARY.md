## 🎮 What You Got

### 1. Six Unique Enemy Types ⚔️

Each with completely unique:

- **Procedural geometry** (no simple shapes!)
- **Distinct AI behaviors**
- **Custom animations**
- **Attack patterns**
- **Visual effects**

**Enemy Roster:**

1. **Trojan Virus** - Rotating dodecahedron with extending spikes, aggressive charge behavior
2. **Worm Virus** - Segmented body with snake-like movement and trailing particles
3. **Spyware Virus** - Crystalline structure with teleportation and ranged attacks
4. **Ransomware Virus** - Fortress design with shield system and orbital armor plates
5. **Adware Virus** - Billboard popup with erratic swarming behavior
6. **Rootkit Virus** - Massive boss with tendrils, orbital rings, multiple phases

### 2. Four Advanced Weapons 🔫

Each with unique projectiles and behaviors:

1. **Pulse Cannon** - Rapid-fire energy weapon (starter)
2. **Laser Rifle** - High-speed beam weapon with elongated projectiles
3. **Plasma Launcher** - Explosive orbs with splash damage and field effects
4. **Shockwave Emitter** - Spread-shot pattern with ring projectiles

## 🎯 How to Use This Project

### Play the Game

```bash
npm start
```

### Develop & Extend

```bash
npm run dev  # With DevTools
```

### Build Executable

```bash
npm run build:win   # Windows
npm run build:mac   # macOS
npm run build:linux # Linux
```

### Add Content

1. New enemies: Follow template in `DEVELOPMENT.md`
2. New weapons: Extend `BaseWeapon` class
3. New effects: Add to `ParticleSystem`
4. Modify difficulty: Edit wave manager or enemy stats
