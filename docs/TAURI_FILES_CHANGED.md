## 🚀 Build Process Flow

### Development (`npm run dev`)
```
1. vite dev server starts → localhost:5173
2. Frontend loads from dev server
3. tauri dev launches window
4. Window connects to localhost:5173
5. Hot-reload on file changes
```

### Production (`npm run build`)
```
1. vite build → creates build/renderer/
2. Tauri builder reads tauri.conf.json
3. Compiles main.rs → Rust binary
4. Bundles frontend into binary
5. Creates platform-specific installer
   Windows: .exe via NSIS
   Mac: .dmg bundle
   Linux: AppImage
```
